# Code of Conduct

We are committed to a respectful, inclusive, and harassment-free project.

Contributors must communicate constructively, respect differing viewpoints,
accept responsibility for mistakes, and focus criticism on ideas and code
rather than people. Harassment, discrimination, threats, deliberate
intimidation, doxxing, and disclosure of another person's private information
are not acceptable.

Project maintainers may remove, edit, or reject contributions and may
temporarily or permanently restrict participation when conduct is
inappropriate, threatening, harmful, or disruptive.

Report conduct concerns privately to the repository maintainers through an
appropriate private GitHub contact channel. Do not include sensitive personal
information in a public issue. Maintainers should handle reports discreetly
and avoid conflicts of interest.
