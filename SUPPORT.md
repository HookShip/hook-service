# Support

Use GitHub issues for reproducible defects and scoped project questions. Use
GitHub Discussions if enabled for broader design conversation.

Do not post vulnerabilities or sensitive data publicly; follow
[`SECURITY.md`](SECURITY.md). This community project does not publish support
response times, uptime commitments, or service-level guarantees.

Early source evaluators should use the
[delivery-service evaluation guide](docs/evaluation.md) and the
organization-wide
[tester program](https://github.com/HookShip/.github/blob/main/TESTING.md)
before submitting feedback.
